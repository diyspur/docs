## 1. Dicionário Tipado de Telemetria de Produto (PostHog)

Para evitar poluição de dados e garantir conformidade com a LGPD, o DIYSpur não envia eventos arbitrários. Toda a telemetria é governada pelo contrato TypeScript **`ProductEventMap`** (`src/lib/analytics.ts`):

```typescript
export type ProductEventMap = {
  sign_up_completed: {
    method: 'email' | 'google' | 'magic_link';
    source_path?: string;
  };
  book_detail_viewed: {
    book_id: string;
    book_title: string;
    has_active_season: boolean;
  };
  season_joined: {
    season_id: string;
    book_id?: string;
    club_id?: string;
  };
  chapter_marked_read: {
    chapter_id: string;
    chapter_number?: number;
    days_since_start?: number;
  };
  comment_submitted: {
    chapter_id: string;
    has_spoiler_flag: boolean;
  };
  calendar_event_clicked: {
    event_id: string;
    book_title?: string;
    platform?: string;
  };
  affiliate_link_clicked: {
    book_id?: string;
    retailer: 'amazon' | 'travessa' | 'kobo';
  };
  share_book_clicked: {
    book_slug: string;
    share_method: 'native' | 'clipboard';
  };
};
```

### 1.1 Invariantes da Telemetria
1. **Ativação Estritamente Condicional (Opt-In):** Se o usuário não concedeu permissão explícita no banner de privacidade, `trackEvent()` encerra silenciosamente sem emitir pacotes de rede.
2. **Zero PII (Personally Identifiable Information):** E-mails, nomes de batismo, senhas ou conteúdos textuais de diários nunca são injetados nas propriedades dos eventos.
3. **Resiliência a Falhas:** Exceções no runtime do PostHog são absorvidas em blocos `try/catch` com fallback silencioso para que falhas de analytics jamais interrompam a leitura do usuário.

## 2. Logs Estruturados e Sanitização contra Vazamento de Memória

O módulo `src/lib/observability/logger.ts` padroniza os logs do servidor em JSON estruturado com uma lista estrita de chaves permitidas (`ALLOWED_LOG_KEYS`):

```json
{
  "service": "diyspur-web",
  "environment": "production",
  "level": "error",
  "event": "quiz_submission_failed",
  "request_id": "req_8f1a23c4",
  "route": "/capitulos/3a687744-...",
  "duration_ms": 42,
  "status_code": 400,
  "error_code": "INVALID_QUESTION_SET"
}
```

- **Truncamento de Segurança:** Valores textuais são truncados em no máximo **200 caracteres** para evitar estouro de memória (*buffer bloat*) e impedir a persistência involuntária de payloads brutos em logs de auditoria.

## 3. Headers HTTP de Segurança e Content Security Policy (CSP)

Configurados em `next.config.mjs`, os cabeçalhos de segurança protegem o leitor contra ataques de injeção de script (XSS), sequestro de cliques (*clickjacking*) e interceptação:

```javascript
const securityHeaders = [
  { key: 'Strict-Transport-Security', value: 'max-age=63072000; includeSubDomains; preload' },
  { key: 'X-Content-Type-Options', value: 'nosniff' },
  { key: 'Referrer-Policy', value: 'strict-origin-when-cross-origin' },
  { key: 'X-Frame-Options', value: 'DENY' },
  { key: 'Permissions-Policy', value: 'camera=(), microphone=(), geolocation=()' },
  {
    key: 'Content-Security-Policy-Report-Only',
    value: [
      "default-src 'self'",
      "frame-src https://www.youtube.com https://www.youtube-nocookie.com",
      "connect-src 'self' https://*.supabase.co wss://*.supabase.co https://*.posthog.com https://*.sentry.io",
      "img-src 'self' data: blob: https://*.supabase.co https://*.record.com.br https://*.amazon.com.br",
      "upgrade-insecure-requests",
    ].join('; '),
  },
];
```

## 4. Mitigação de Open Redirects (`safeLocalRedirect`)

O helper `src/lib/safe-redirect.ts` previne que atacantes forjem URLs de retorno pós-login (ex.: `?returnUrl=//attacker.com` ou `/\\malicious.site`):

```typescript
export function safeLocalRedirect(value: string | null | undefined, fallback = '/perfil'): string {
  if (!value || typeof value !== 'string') return fallback;
  const trimmed = value.trim();
  
  // Bloqueia barras duplas, barras invertidas e protocolos absolutos
  if (!trimmed.startsWith('/') || trimmed.startsWith('//') || trimmed.startsWith('/\\')) {
    return fallback;
  }
  
  try {
    const parsed = new URL(trimmed, 'https://local.invalid');
    if (parsed.origin !== 'https://local.invalid' || !parsed.pathname.startsWith('/')) {
      return fallback;
    }
    return `${parsed.pathname}${parsed.search}${parsed.hash}`;
  } catch {
    return fallback;
  }
}
```

## 5. Calendário e Dados Estruturados (RFC 5545 & Schema.org)

O módulo `src/lib/calendar-links.ts` automatiza a geração de convites e enriquecimento semântico:
- **RFC 5545 (iCalendar .ics):** A função `escapeIcs()` trata quebras de linha (`\n`), vírgulas e pontos-e-vírgulas, removendo caracteres de controle Unicode (`\u0000-\u001F`) para garantir compatibilidade com Apple Calendar e Microsoft Outlook.
- **Google Agenda Web:** Geração de deep-links com parâmetro `action=TEMPLATE` convertendo as datas para o formato compacto UTC e fixando a legenda com o fuso oficial de Brasília (`America/Sao_Paulo`).
- **Schema.org Virtual Event:** Injeção de JSON-LD com `eventAttendanceMode = 'OnlineEventAttendanceMode'`, permitindo que o Google exiba rich snippets dos encontros virtuais nos resultados de busca orgânica.
