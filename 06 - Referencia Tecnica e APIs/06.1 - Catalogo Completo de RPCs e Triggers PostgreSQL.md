## 1. Visão Geral das Chamadas Remotas de Procedimento (RPCs)

Todas as RPCs do DIYSpur seguem um padrão arquitetural uniforme:
- **Segurança:** Funções sensíveis residem com atributo `SECURITY DEFINER` e cláusula obrigatória `SET search_path = ''`.
- **Privilégios:** Apenas funções explicitamente públicas recebem `GRANT EXECUTE` para `authenticated`. Funções de infraestrutura ou serviços recebem `GRANT EXECUTE` unicamente para `service_role`.
- **Concorrência:** Operações de mutação de estado utilizam checagem de versão esperada (`p_expected_version`) ou locks atômicos (`FOR UPDATE`).

## 2. Catálogo das Funções RPC

### 2.1 Discussões & Chat de Clubes

#### `post_club_message`
- **Assinatura:** `post_club_message(p_channel_id uuid, p_content text, p_parent_id uuid DEFAULT NULL, p_is_spoiler boolean DEFAULT false, p_idempotency_key uuid DEFAULT NULL) RETURNS jsonb`
- **Segurança:** `SECURITY DEFINER`, `search_path = ''`, executável por `authenticated`.
- **Regras:**
  1. Identifica o autor via `(SELECT auth.uid())`.
  2. Valida acesso ao canal via `is_channel_accessible(p_channel_id)`.
  3. Checa sanções ativas via `check_member_active_sanctions`.
  4. Garante que `p_parent_id`, se fornecido, pertence estritamente ao mesmo `p_channel_id`.
  5. Se `p_idempotency_key` já existir para o usuário, retorna o registro já gravado.
- **Erros:** `channel_access_denied`, `user_is_banned_from_club`, `cross_channel_parent_reply_denied`.

#### `edit_club_message`
- **Assinatura:** `edit_club_message(p_message_id uuid, p_new_content text, p_expected_version integer) RETURNS jsonb`
- **Segurança:** `SECURITY DEFINER`, executável por `authenticated`.
- **Regras:**
  1. Bloqueia a linha da mensagem com `FOR UPDATE`.
  2. Valida se o usuário autenticado é o autor da mensagem (`user_id = auth.uid()`).
  3. Compara `version = p_expected_version`. Se diferente, aborta a transação.
  4. Incrementa `version`, atualiza `content`, marca `is_edited = true` e grava `updated_at = now()`.
- **Erros:** `message_not_found_or_not_owner`, `version_mismatch: message was modified concurrently`.

#### `delete_club_message`
- **Assinatura:** `delete_club_message(p_message_id uuid) RETURNS boolean`
- **Regras:** Permite que o próprio autor ou um moderador/dono do clube execute a exclusão lógica da mensagem (marcando `is_deleted = true` e ocultando o texto original).

#### `toggle_message_reaction`
- **Assinatura:** `toggle_message_reaction(p_message_id uuid, p_emoji text) RETURNS jsonb`
- **Regras:** Adiciona a reação de emoji caso o leitor ainda não tenha reagido, ou a remove caso já tenha selecionado anteriormente (operação atômica).

#### `set_spoiler_consent`
- **Assinatura:** `set_spoiler_consent(p_channel_id uuid, p_consented boolean) RETURNS boolean`
- **Regras:** Registra o consentimento voluntário do leitor em acessar um canal de discussões avançadas com spoilers (`channel_members_spoiler_consent`), persistindo data e identificador de usuário.

### 2.2 Leitura Canônica & Estante

#### `update_canonical_reading_status`
- **Assinatura:** `update_canonical_reading_status(p_book_id uuid, p_status book_reading_status, p_edition_id uuid DEFAULT NULL, p_page integer DEFAULT NULL, p_rating integer DEFAULT NULL, p_review text DEFAULT NULL) RETURNS jsonb`
- **Segurança:** `SECURITY DEFINER`, executável por `authenticated`.
- **Regras:**
  1. Insere ou atualiza o registro em `user_book_readings` para o leitor logado.
  2. Fiscaliza a transição de estado permitida via trigger `trg_validate_book_reading_transition`.
  3. Atualiza timestamps de início (`started_at`) e término (`finished_at`) de acordo com o status.
  4. Dispara a atualização das agregações comunitárias da obra.

### 2.3 Notificações & Outbox

#### `get_user_notifications_v2`
- **Assinatura:** `get_user_notifications_v2(p_limit integer DEFAULT 20, p_offset integer DEFAULT 0, p_channel text DEFAULT NULL, p_unread_only boolean DEFAULT false) RETURNS SETOF public.notifications`
- **Regras:** Retorna a listagem paginada de notificações do usuário com suporte a filtros por canal sem expor dados de terceiros.

#### `mark_notifications_read`
- **Assinatura:** `mark_notifications_read(p_notification_ids uuid[] DEFAULT NULL) RETURNS integer`
- **Regras:** Marca como lidas (`read_at = now()`) as notificações especificadas no array, ou todas as notificações pendentes do leitor caso `p_notification_ids` seja nulo.

#### `claim_notification_outbox`
- **Assinatura:** `claim_notification_outbox(p_batch_size integer DEFAULT 50) RETURNS SETOF public.notification_outbox`
- **Segurança:** Concedida apenas a `service_role`.
- **Regras:** Seleciona até `p_batch_size` registros com `status = 'pending'` ordenados por data de agendamento usando `FOR UPDATE SKIP LOCKED`, alterando o status para `'processing'`.

#### `resolve_notification_outbox`
- **Assinatura:** `resolve_notification_outbox(p_outbox_id uuid, p_success boolean, p_error text DEFAULT NULL) RETURNS void`
- **Regras:** Marca o item como `'delivered'` em caso de sucesso, ou incrementa o contador de retentativas (`retry_count`) e agenda novo envio em caso de falha transitória.

### 2.4 Moderação & Denúncias

#### `report_content`
- **Assinatura:** `report_content(p_content_type text, p_content_id uuid, p_reason text, p_notes text DEFAULT NULL) RETURNS uuid`
- **Regras:** Cria um novo registro em `content_reports` registrando o denunciante, tipo de recurso e justificativa. Se o recurso acumular 3 denúncias ativas, aciona a flag temporária `is_hidden = true`.

#### `moderate_content_report`
- **Assinatura:** `moderate_content_report(p_report_id uuid, p_action text, p_admin_notes text DEFAULT NULL) RETURNS boolean`
- **Segurança:** Restrita a administradores via `is_admin_or_superadmin()`.
- **Ações Aceitas:** `hide_content` (oculta permanentemente), `resolve` (marca denúncia como procedente), `dismiss` (descarta como improcedente e restaura visibilidade).

## 3. Catálogo dos Gatilhos de Integridade (Triggers)

| Nome do Trigger | Tabela Alvo | Evento | Comportamento e Regra de Negócio |
|---|---|---|---|
| `trg_validate_book_reading_transition` | `user_book_readings` | `BEFORE UPDATE` | Impede saltos diretos de `want_to_read` para `read` sem passar por `reading`. Ajusta percentual e timestamps. |
| `trg_sync_book_reading_aggregates` | `user_book_readings` | `AFTER INSERT OR UPDATE OR DELETE` | Atualiza contadores comunitários na tabela agregada de leitores ativos e concluídos. |
| `trg_validate_club_message_parent` | `club_messages` | `BEFORE INSERT` | Garante que respostas encadeadas (`parent_id`) pertençam estritamente ao mesmo `channel_id`. |
| `trg_ensure_official_book_group` | `books` | `AFTER INSERT` | Cria automaticamente o clube oficial da obra e seus canais estruturados quando um livro é cadastrado. |
| `trg_auto_flag_reported_content` | `content_reports` | `AFTER INSERT` | Verifica se o número de denúncias distintas para o mesmo recurso atingiu o limiar de 3, ativando ocultação preventiva. |
| `trg_prevent_direct_role_escalation` | `profiles` | `BEFORE UPDATE` | Impede que usuários sem privilégios alterem suas próprias colunas de autorização (`role`, `is_admin`). |
| `trg_reading_journal_likes_counter` | `reading_journal_likes`| `AFTER INSERT OR DELETE` | Recalcula de forma atômica a contagem de curtidas em `reading_journal_entries.likes_count`. |
| `trg_book_poll_votes_counter` | `book_poll_votes` | `AFTER INSERT OR UPDATE OR DELETE` | Atualiza a quantidade de votos em `book_poll_options.votes_count`. |
| `trg_update_timestamp` | Múltiplas tabelas | `BEFORE UPDATE` | Atualiza automaticamente a coluna `updated_at = now()`. |
