## 1. O Subsistema de Avaliações Comunitárias (`book_reviews`)

Projetado para dar voz aos leitores após a conclusão da temporada, o modelo `public.book_reviews` combina métricas quantitativas de alta precisão com expectativas da cultura literária contemporânea (BookTok / BookTube):

```sql
CREATE TABLE public.book_reviews (
  id                uuid primary key default gen_random_uuid(),
  book_id           uuid not null references public.books(id) on delete cascade,
  user_id           uuid not null references public.profiles(id) on delete cascade,
  rating            numeric(3,2) check (rating is null or rating between 0 and 5),
  spice_level       integer check (spice_level is null or spice_level between 0 and 5),
  review_text       text check (review_text is null or length(review_text) <= 20000),
  contains_spoilers boolean not null default false,
  deleted_at        timestamptz,
  created_at        timestamptz not null default now(),
  updated_at        timestamptz not null default now(),
  constraint book_reviews_one_per_user_book unique (book_id, user_id)
);
```

### 1.1 O Indicador de "Spice Level" (0 a 5)
Um dos diferenciais conceituais do DIYSpur é a mensuração explícita do **Spice Level** (nível de intensidade de romance e cenas explícitas):
- **Nível 0:** Ausência de romance ou abordagem estritamente platônica/inocente.
- **Nível 1–2:** Romance focado em tensão emocional, beijos e sentimentos sem detalhamento físico explícito (*closed door*).
- **Nível 3:** Cenas íntimas com detalhamento moderado e linguagem sensorial (*open door*).
- **Nível 4–5:** Cenas recorrentes, explícitas e centrais para o arco do relacionamento.

Esse metadado permite que leitores filtrem obras alinhadas ao seu perfil de conforto, complementando os **Avisos de Conteúdo** (*Content Warnings*).

## 2. Agregações Cegas de Audiência no Schema `private`

Para permitir que anfitriões e participantes visualizem estatísticas gerais da comunidade sem expor o progresso individual de ninguém, o banco implementa funções de **agregação cega** (`private.get_chapter_audience`):

```sql
CREATE OR REPLACE FUNCTION private.get_chapter_audience(p_chapter_id uuid)
RETURNS TABLE (
  finished_count    bigint,
  reading_count     bigint,
  not_started_count bigint,
  avg_percent       numeric
)
LANGUAGE sql STABLE SECURITY DEFINER SET search_path = pg_catalog
AS $$
  SELECT
    count(*) FILTER (WHERE p.status = 'read'),
    count(*) FILTER (WHERE p.status = 'reading'),
    count(*) FILTER (WHERE p.status = 'want_to_read'),
    round(avg(p.percent)::numeric, 2)
  FROM public.user_progress AS p
  WHERE p.chapter_id = p_chapter_id;
$$;
```

### 2.1 Garantias de Privacidade
- O schema `private` **não é exposto à Data API / PostgREST**.
- A função retorna apenas contagens somadas e médias numéricas arredondadas, tornando matematicamente impossível deduzir quais leitores específicos estão atrasados ou adiantados na leitura.
